# chofito.github.io — Agent Guide

## Overview

Personal portfolio site for Rodolfo "Chofito" Robles. The UI mimics a Cursor-style
editor window with two tabs: an animated **Terminal** demo and a syntax-highlighted
**bio.ts** view.

**Stack:** React 19, Vite, TypeScript, Tailwind CSS v4, Biome (lint/format).

**Tooling:** [Bun](https://bun.sh) for install, dev, build, and CI. Deployed to
GitHub Pages via GitHub Actions.

## Commands

```bash
bun install
bun run dev          # Vite dev server
bun run build        # tsc -b && vite build
bun run check        # Biome lint + format check
bun run check:fix    # Biome safe fixes + format
bun run lint         # Biome lint only
bun run format       # Biome format only
bun run preview      # preview production build
```

Lint and format use **Biome**, not ESLint or Prettier.

## Architecture

### Shell

`src/App.tsx` holds tab state and persists the active tab to `localStorage`
(guarded with try/catch). It renders `EditorWindow` → `TabBar` + `TabPanel`.

Both tab panels stay mounted. Inactive panels use the `hidden` attribute and pass
`isActive={false}` to the terminal, which pauses animation without resetting state.

### Terminal (data-driven)

```
config.ts  →  script.ts  →  builders.ts  →  parseRich.ts  →  components
```

| Layer | File | Role |
|-------|------|------|
| Copy + markup | `src/data/terminal/config.ts` | Terminal strings with rich markup tags |
| Command list | `src/data/terminal/script.ts` | Assembles `terminalCommands` via builders |
| Builders | `src/data/terminal/builders.ts` | `cmd`, `richStr`, `loader`, `list`, `links`, `neofetchFromConfig`, etc. |
| Parser | `src/data/terminal/parseRich.ts` | Markup string → `RichSpan[]` |
| Types | `src/data/terminal/types.ts` | `OutputLine`, `TerminalCommand`, `RichSpan` |
| Render | `src/components/terminal/` | `TerminalTab` → `CommandBlock` → `TypewriterLine` / `TerminalOutput` → line components |

### "Shaders"

CSS keyframe effects in `src/index.css`:

- `text-shimmer` — animated gradient text
- `text-glow` — pulsing glow
- `text-glitch` — jitter transform
- `cursor-blink` — block cursor blink

JS-driven spinners via `AsciiLoader` (`dots`, `braille`, `bar` variants).

Both respect `prefers-reduced-motion: reduce` (hook + CSS media query).

### Bio tab

`src/data/profile.ts` is the single source of profile data.
`src/data/bioCode.ts` renders the object literal as syntax-highlighted tokens.
`src/components/code/CodeEditor.tsx` / `SyntaxLine` / `LineGutter` display them.

`src/data/bioHelpers.ts` shares link resolution (`resolveLinkHref`, `toLinkEntries`)
with the terminal `links()` builder.

## Where to edit content

| What | Where |
|------|-------|
| Profile data (bio tab) | `src/data/profile.ts` |
| Terminal copy + markup | `src/data/terminal/config.ts` |
| Terminal command order | `src/data/terminal/script.ts` |
| Link URLs (terminal `ls ./links`) | `profile.links` in `profile.ts` |

Do **not** hand-edit the rendered bio tokens — they are generated by `bioCode.ts`
from `profile.ts`.

## Rich markup / shader reference

Used in `config.ts` strings and parsed by `parseRich.ts`:

| Markup | Effect |
|--------|--------|
| `**text**` | bold |
| `*text*` | italic |
| `~~text~~` | strikethrough |
| `{dim:text}` | dim color |
| `{amber:text}` | amber accent |
| `{accent:text}` | purple accent |
| `{shimmer:text}` | animated gradient (`text-shimmer`) |
| `{glow:text}` | pulsing glow (`text-glow`) |
| `{glitch:text}` | glitch jitter (`text-glitch`) |
| `{loader:dots}` | inline `.` / `..` / `...` spinner |
| `{loader:braille}` | braille spinner |
| `{loader:bar}` | `[====    ]` progress bar |

Tags map to `TAG_STYLES` in `parseRich.ts`. Keep this table in sync when adding tags.

### Builders (`builders.ts`)

```ts
cmd(input, ...lines)           // wrap input + output lines
rich`…` / richStr(string)      // parse rich markup into spans
blank()                        // empty line
loader(variant, label?)         // standalone ASCII loader line
list(items)                    // plain-text list (no markup)
links()                        // profile link rows
neofetchFromConfig()           // neofetch rows from config
```

## Conventions

- Functional components and hooks only.
- Terminal content is data-driven — avoid hardcoded JSX for copy.
- **Biome** formatting: single quotes, double JSX quotes, semicolons, trailing
  commas, 2-space indent, 80-char line width.
- No default exports except `*.config.*` files (see `biome.json` override).
- React 19 with `StrictMode` in `main.tsx`.
- Strict TypeScript: `noUnusedLocals`, `noUnusedParameters` enabled.

## Accessibility

- Honor `prefers-reduced-motion` via `usePrefersReducedMotion` hook:
  terminal skips animation, loaders freeze, CSS effects rest.
- Tab bar uses ARIA `tablist` / `tab` / `tabpanel` roles.
- Roving `tabIndex` (0 on active, -1 on others) with ArrowLeft/Right, Home/End
  keyboard navigation in `TabBar.tsx`.
- `localStorage` access is wrapped in try/catch for private browsing.

## Deploy

Push to `main` triggers `.github/workflows/deploy.yml`:

1. `bun install --frozen-lockfile`
2. `bun run build`
3. Upload `dist/` to GitHub Pages

One-time setup: repo **Settings → Pages → Source → GitHub Actions**.

## Future direction

Extract the terminal system (`parseRich`, builders, types, shader CSS, line
components) into a self-contained reusable module or package so others can build
their own animated terminal UIs from config data.

The existing boundary — `config.ts` / `builders.ts` / `types.ts` on the data side,
`TerminalTab` and line components on the render side — is the natural seam for
that extraction.

**Not planned yet:** interactive command input, theme toggle, copy-to-clipboard
email, OG/Twitter meta tags.
